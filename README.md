# Py_Tkinter_App
Python/Tkinter inventory management app for tracking machine parts. Uses MySQL to manage inventory, scan part numbers, add stock, and record parts used on Machine 1 or Machine 2. Built to simplify real-time parts tracking and maintenance inventory management.
